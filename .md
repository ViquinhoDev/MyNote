# Versões e Melhorias – MyNote

| Versão | Tipo | Principais melhorias |
|--------|------|----------------------|
| 1.0.0 | Major | Lançamento inicial: 4 idiomas, CRUD, formatação, limite de caracteres, modo escuro, export/import .txt, auto‑save, Ctrl+S, responsivo. |
| 1.0.1 | Patch | Correção de bugs no modal de importação e no auto‑salvamento; melhorias de desempenho. |
| 1.0.2 | Patch | Correção de bugs na importação .txt e no contador de caracteres ao colar; pequenos ajustes na interface. |
| 1.0.3 | Patch | Correção de bugs no modal de nova nota e ao excluir nota ativa; melhor feedback visual ao salvar. |
| 1.1.0 | Minor | Pesquisa e filtro de notas; ordenação por data/título/modificação; contador de palavras; atalhos Ctrl+N (nova) e Ctrl+E (exportar). |
| 1.1.1 | Patch | Correção de bugs ao criar nota sem título e no Ctrl+S em alguns navegadores. |
| 1.1.2 | Patch | Ajustes visuais no modo escuro; correção de bug no carregamento inicial. |
| 1.1.3 | Patch | Correção de bugs ao salvar nota com título vazio e no cálculo do contador; mensagens de alerta mais claras; melhorias de acessibilidade. |
| 1.2.0 | Minor | Categorias/tags; filtro por tags; fixar notas no topo; interface da barra lateral redesenhada; limite de notas aumentado para 20. |
| 1.2.1 | Patch | Correção de bugs ao importar arquivos vazios e ao exportar com caracteres especiais; melhor feedback visual. |
| 1.2.2 | Patch | Correção de bug ao colar texto com formatação; melhorias no auto‑salvamento; ajustes na barra de status. |
| 1.3.0 | Minor | Exportação/importação em lote (`.json` e `.txt`); backup manual com um clique; restauração de backup. |
| 1.3.1 | Patch | Ajustes de layout no modo escuro; correção de bug ao deletar última nota; melhorias na responsividade. |
| 1.4.0 | Minor | Exportação como PDF; importação de `.md` (Markdown); modo leitura (sem distrações); correção de bugs com acentos. |
| 1.5.0 | Minor | Tamanho de fonte ajustável; modo tela cheia (F11); estatísticas (tempo de leitura, parágrafos); limite de notas aumentado para 25. |
| 1.6.0 | Minor | Atalhos adicionais (Ctrl+N, Ctrl+E, Ctrl+Shift+D); menu de contexto (clique direito); arrastar e soltar para reordenar; melhorias no foco automático. |
| 1.7.0 | Minor | Pesquisa avançada (título, conteúdo, data); ordenação adicional; contador de palavras aprimorado; correção de bug com caracteres especiais. |
| 1.8.0 | Minor | Categorias e tags aprimoradas; cores personalizadas para notas; mais opções de fixação; interface mais rápida. |
| 1.9.0 | Minor | Exportação/importação em lote aprimorada; backup automático programado; restauração simplificada; melhorias de performance. |
| 2.0.0 | Major | Sincronização com a nuvem (Firebase); compartilhamento de notas via link; histórico de versões (undo/redo); autenticação de usuários; notas colaborativas; interface totalmente redesenhada; migração para IndexedDB; fim do suporte a navegadores antigos. |
