**Version:** 1.0.0  
**Status:** 🚧 In development  
**Languages:** Portuguese (PT), English (EN), Spanish (ES), French (FR)

---

## 📖 About

MyNote is a lightweight, client‑side notes application that runs entirely in your browser.  
It allows you to create, edit, delete, export, and import notes, with real‑time character counting, dark mode, and auto‑save.

Currently available in **four languages** – just open the corresponding HTML file:

- `PT.html` – Português  
- `EN.html` – English  
- `ES.html` – Español  
- `FR.html` – Français  

All versions share the same functionality and are fully self‑contained.

---

## 🚀 Features

- Create, edit, and delete notes (up to 10 notes)
- Rich text formatting (bold, italic, underline, bullet/numbered lists)
- Character limit: 4,500 characters with visual warning
- Dark / Light mode (persisted in localStorage)
- Export notes as `.txt` files
- Import notes from `.txt` files
- Auto‑save every 30 seconds and `Ctrl+S` shortcut
- Fully responsive design

---

## 🛠️ How to Use

1. Clone this repository or download the desired HTML file.
2. Open the file in any modern browser (Chrome, Firefox, Edge, etc.).
3. Start taking notes – your data is saved locally in your browser’s storage.

No installation, no server, no external dependencies – just HTML, CSS, and vanilla JavaScript.
